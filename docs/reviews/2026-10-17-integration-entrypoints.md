Its file header at `:3` says it is not wired into dashboard, but actual route calls above make that comment stale. This method cannot be the managed execution primitive. - [ ] **Cancel:** `bot/live_coinbase_adapter.py:104` forwards directly to `client.cancel_order` at `:105` with no authority epoch/actor checks. - [ ] **Replace:** no implemented legacy replacement handler or adapter replacement method was found. `bot/autonomous/ledger.py:534` explicitly defers reduction/replacement ordinal allocation; `reserve_intent` rejects those slots at `:536`. ## Browser authentication, read models and failures

- [ ] Apply operator session checks to every managed order/control/execute/automation route above. Task 17 requires `401` without session, `403` for wrong role, Origin or CSRF failure; HttpOnly SameSite=Strict session cookies; verified Origin and anti-CSRF nonce on mutations. A POST acknowledgement, JSON Content-Type, local binding, or enabled button does not implement these checks.
- [ ] `dashboard/frontend/index.html:52` is the shared fetch helper; it currently only adds JSON Content-Type. Preserve existing operator frontend edits while connecting the approved session/nonce flow. Do not make UI disabling the authorization boundary or place implementation/credential configuration in product flows.
- [ ] Authority authenticates the forwarded actor and role capability independently. Bind request identity to actor/account/mode/epoch/payload; identical retries return original receipt, altered payload rejects. A browser-selectable command kind must not access worker-only judgment/import/risk wiring, release activation or review resolution beyond its authenticated capability. The public `ControlCommand.actor` field (`contracts.py:1035`) is not proof of identity.
- [ ] Managed `/api/status` currently derives portfolio/gates from legacy tables (`dashboard/backend/app.py:300`–`:304`); `/api/automation` reads legacy state at `:390`; `/api/live/status` reads venue config at `:412`–`:432`; order histories read independent paper/live tables at `:700` and `:514`. Replace managed state with authority read models without constructing adapters or loading secrets. Preserve public market/history/strategy catalog behavior; `/ws/live` (`:706`) currently only sends market prices and is not an order path. `/api/ai/analyze` (`:312`) records advice without execution and must stay nonexecuting.
- [ ] Absent client, socket unavailable, invalid peer/session/capability, stale epoch/boot/account/mode, unavailable read state or unsupported command: reject managed mutation explicitly. Never fall back to `execute_order`, paper helper, legacy account SQL, live construction or local arming. Use the project-approved unavailable response when defined; Task 17 does not prescribe a numeric status for transport outage. Typed risk/control rejection is `409`; accepted pending commands are `202` with request/intent identity and status, not `filled`.
- [ ] A timeout after command send is uncertain: show pending/unknown and retry/query the same request ID rather than minting another action or claiming success/failure of venue execution. Preserve authoritative reservations and reconciliation responsibility. Managed dependency absence must not silently open operator defaults: dashboard import currently invokes `init_db()` at `dashboard/backend/app.py:109`, whose default DB comes from `:31`; injected integration/tests must isolate this legacy initialization from authoritative state and any operator DB fallback.
