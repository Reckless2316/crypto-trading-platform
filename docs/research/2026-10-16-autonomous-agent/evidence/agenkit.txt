The solo-builder tax
You're doing the job of an entire team, alone.
The gap isn't effort. It's expertise. A generalist writes the code; a specialist knows the production concerns you didn't think to ask about.
What a specialist actually considers
Watch one agent reason through a routine task - the idempotency, reconciliation, indexes, and async calls a solo generalist quietly skips. That gap is what AgenKit closes, automatically.
Backend Architect
thinking about:
accept Stripe webhooks
✓
Make it idempotent: retries deliver the same event twice; dedupe by event id.
✓
Verify the signature before trusting a single byte of the payload.
✓
This is I/O-bound → run it async, with a timeout, retry, and backoff.
✓
Store the raw event first, ack fast, process out of band.
✓
Reconcile daily against Stripe; webhooks do get dropped.
Data Engineer
thinking about:
list a user's recent orders
✓
This query full-scans; add a composite index on (user_id, created_at).
✓
Page with a keyset cursor, not OFFSET, or page 900 crawls.
✓
That migration locks the table; run it online and backfill in batches.
✓
Don't SELECT * across a join you never read; it bloats the plan.
Security Engineer
thinking about:
add a file upload
✓
Validate the type by magic bytes, not the filename extension.
✓
Store outside the web root; serve via a signed, expiring URL.
✓
Cap the size and rate-limit; an unbounded upload is a DoS.
✓
Strip metadata and re-encode; uploads smuggle EXIF and payloads.
Decisions a generalist skips, applied automatically.

FAQ
Questions, answered.
Still curious? Everything installs locally and keeps working offline once installed.
01
Which tools does it work with?
+
All seven: Claude Code, Cursor, Codex CLI, OpenCode, Antigravity CLI, GitHub Copilot, and Kimi Code. The kit is compiled to the exact file layout each tool expects.
02
How do I start it in my tool?
+
Trigger AgenKit with /agenkit in most tools (Claude Code, Cursor, OpenCode, Antigravity, and Kimi Code). In GitHub Copilot it's @agenkit, and in Codex you invoke the AgenKit skill by name. The install step prints the exact trigger for your harness.
03
What exactly do I get?
+
The Engineering Kit - a full team of specialist agents, the process skills that guide them, and the /agenkit command - delivered as versioned archives installed by the agenkit CLI. Your license key is the only credential; there is no account to manage.
04
Do I need to create an account?
+
No. Checkout issues a license key via Polar; the CLI stores it locally and the API validates it on install.
05
Is it one-time or a subscription?
+
A simple subscription that works out to just $3.49/mo (billed yearly). Early subscribers keep that founding rate while subscribed; after that it's $15/mo. It covers every update while active, across all seven harnesses. Cancel any time; the installed kit keeps working locally.
06
How do updates work?
+
Run agenkit update. It compares your lockfile to the latest versions and refreshes everything your subscription unlocks.
07
Is there a refund policy?
+
Yes - a 14-day money-back window, handled through Polar's customer portal.
08
Is AgenKit related to OpenAI's AgentKit?
+
No. AgenKit (agenkit.xyz) is an independent product: a guided engineering team you install into Claude Code, Cursor, Codex, and other harnesses. It is not affiliated with OpenAI AgentKit.
