L89: attach_assets
L90: 
L91: Attach assets to calls made within a `with` block, for referencing them inside strings. Until the block exits, calls on this client send each attached asset whose reference, `str(asset)`, appears in the request.
L92: 
L93: Warning The SDK only recognizes references to assets that are attached, passed in `assets`, or placed directly in the content. A reference to any other asset is sent as plain text, without the asset.
L94: 
L95: Parameters:
L96:   * `assets` (`cite16†Asset | cite17†Sequence†docs.python.org [cite16†Asset ]`) – An asset, or a sequence of them.
L97: Raises:
L98:   * `cite12†TypeSafeError ` – An attached value is not an asset.
L99: Examples:
L100: 
L101:     `from pathlib import Path
L102: 
L103:     from typesafe_sdk import AsyncTypeSafeClient, Image, Noul, SystemOneResponse
L104:

L106:     async def inspect(client: AsyncTypeSafeClient, path: Path) -> SystemOneResponse:
L107:         photo = Image(path)
L108:         with client.attach_assets(photo):
L109:             return await client.system_one(
L110:                 state=f"Product: {photo}",
L111:                 questions={"damaged": Noul(instructions="Is the product damaged?")},
L112:             )
